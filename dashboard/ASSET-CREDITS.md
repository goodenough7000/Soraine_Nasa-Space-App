# Planet imagery and rendering

The globe uses JavaScript and Three.js 0.160.0 (MIT, included in `dist/vendor/LICENSE-three`). Its day/night blending and atmospheric limb lighting follow the visual ideas in the [Three.js Earth example](https://threejs.org/examples/webgpu_tsl_earth.html). The shader code here is an original WebGL implementation for broad browser support. The reference's Solar System Scope textures are not included.

These are mapped satellite-image composites, not live orbital footage. The decorative orbital paths, lighting, rotation and atmospheric glow are illustrative. The Moon has no atmospheric halo. The Mars halo is deliberately faint. The Moon uses elevation-derived normal shading; the Viking map includes baked image relief. Neither is a navigable terrain or a prediction of fire behavior. NASA's color maps are prepared for visualization, rather than quantitative surface measurements.

NASA material is reused with source credits under its [image and media guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/). No NASA logo or endorsement is used. Fuselab Creative's [CyberDefend](https://fuselabcreative.com/our-projects/cyberdefend/) informed the first layout. The current open layout references [The Bluejack Group Dashboard on Awwwards](https://www.awwwards.com/sites/the-bluejack-group-dashboard). No reference artwork is included.

## Small-screen derivatives

The `*-mobile.webp` assets are resized derivatives of the credited maps above, generated with `scripts/optimize-textures.py`. Colour maps are 1536 × 768 at WebP quality 88. The lunar normal map is 1024 × 512, with vectors renormalized and saved losslessly. These retain the same source credits.

| Derivative | Bytes |
|---|---:|
| Earth colour | 130,996 |
| Earth night lights | 72,776 |
| Moon colour | 199,002 |
| Moon normals | 677,316 |
| Mars colour | 315,430 |

The mobile Moon pair totals 876,318 bytes, compared with 12,133,962 bytes for the detailed pair. This is a file-transfer reduction, not a measured rendering-speed claim. No imagery was generated by AI.

## Original project visuals

The orbital laboratory and decorative orbit treatment are original project geometry created with Codex assistance. The small Earth seen through the laboratory window uses the credited NASA Earth map. These graphics do not model flame behaviour.

The Ultem, Mylar and Nomex specimens in `dist/material-model.mjs` use original procedural 3D geometry, physical shading and a generated fabric texture. No downloaded specimen meshes, photographs or external material textures are used. Their shapes, colours and optical appearance are illustrative, not measured material properties or reconstructions of individual experimental samples. The original SVG illustrations in `dist/specimen.mjs` remain as the loading and WebGL setup fallback. Both versions were created with Codex assistance; neither predicts burning.

## Original soundtrack

**Soraine: Quiet Orbit** is a 53.33-second original ambient waltz created for this project with Codex assistance. Its melody, arrangement and synthesized instruments are defined in `scripts/compose-observatory.py`. It uses no recordings or external samples. The brief asked for a calm observatory mood; no Nintendo melody or soundtrack recording is included. See `dist/assets/audio/README.md` for the score and rendering details. Audio is optional and loads only when the visitor selects Play.
